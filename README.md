# SimLaps – Download

**Rundenzeiten-Rekorder für Sim-Racing.** SimLaps erkennt automatisch Spiel, Strecke, Auto, Lenkrad und Pedale
und zeichnet jede Runde auf. Ein Dashboard vergleicht deine Zeiten pro Strecke über alle Spiele hinweg und zeigt deine Entwicklung.

*erstellt von Andreas Probst · by retr0verse*

## Download

➡️ **[Neueste Version herunterladen](../../releases/latest)** (`SimLaps.zip`)

## Unterstützte Spiele

RaceRoom · Assetto Corsa EVO · Assetto Corsa Rally · Automobilista 2 · iRacing · Le Mans Ultimate (PC)
Gran Turismo 7 · Project Motor Racing (PS5, über das Heimnetz)

## Kurz-Anleitung

1. ZIP entpacken und den Ordner `SimLaps` an einen festen Ort legen, zum Beispiel `C:\Tools\SimLaps` (nicht in „Programme“).
2. `SimLaps.exe` starten. Das Stoppuhr-Symbol erscheint im Infobereich unten rechts.
3. Rechtsklick auf das Symbol → „Mit Windows starten“ anhaken.
4. Fahren. Rechtsklick → „Dashboard öffnen“ zeigt deine Zeiten.

Die ausführliche Anleitung liegt als `LIES-MICH.txt` im ZIP.

**Hinweis:** Die Datei ist nicht signiert. Windows zeigt beim ersten Start „Der Computer wurde durch Windows geschützt“:
„Weitere Informationen“ → „Trotzdem ausführen“.

Alle Spiel- und Herstellernamen gehören ihren jeweiligen Inhabern. SimLaps ist ein unabhängiges Projekt.
